### Memory-Driven Agent System for Longitudinal Insights — Part 2

In the [Part 1](https://s-acharya.medium.com/d04d582fc29d) of this story we examined how Memory-Driven Agent System can help getting more insightful information about a patient. In this part we will see a possible Python based implementation.

To recall , we are trying to implement the following process flow

The key agents in action are:

§ **Data Collector** — Ingests EHR, FHIR, HL7, clinical notes, imaging reports etc.

§ **Memory Manager —** Stores and indexes patient data using vector DB (e.g., FAISS, Qdrant)

§ **Clinical Reasoner** — Synthesizes information across time to generate insight or care suggestions

§ **Explainer —** Translates reasoning into human‑understandable summaries

**Suggested Technical Components**

o **LLM Backend**\- Local (Ollama), vLLM, or OpenAI‑compatible APIs

o **Memory Store**\- FAISS / Qdrant for semantic search of patient history

o **Framework**\- Langgraph, BeeAI

o **Integration**\- Streamlit

For this prototype we would be using

Python : Python3.12, uv as the package manager

We are also using Phoenix ([https://phoenix.arize.com/](https://phoenix.arize.com/)) for agent traceability and telemetry hosted via podman. Please refer to [https://arize.com/docs/phoenix/self-hosting/deployment-options/docker](https://arize.com/docs/phoenix/self-hosting/deployment-options/docker) for the steps.

We have also used a containerized version of Qdrant , please refer to [https://qdrant.tech/documentation/guides/installation/](https://qdrant.tech/documentation/guides/installation/)

The prototype uses Ollama (LLM inference)

**Agent Definition**

**Data Collector Agent** is defined as follows. Since this is a prototype we are using dummy data to simulate data collection scenario.

def data\_collector(patient\_id: str, symptoms: list\[str\], report: Optional\[str\] = None) -\> dict:

Next, Memory Manager Agent and other agents are defined

@tool  
def memory\_manager(data: dict) -\> str:  
    """Tool implementation for memory\_manager."""  
    embedding = np.random.rand(384).tolist()  # simulate embedding  
    collection.add\_texts(  
        texts=\[str(data)\],  
        metadatas=\[{"patient\_id": data\["patient\_id"\], "timestamp": datetime.now().isoformat()}\],  
        ids=\[str(uuid.uuid4())\]  # Ensure UUIDs are used as valid point IDs  
    )  
    memory\_store.append((data\["patient\_id"\], embedding))  
    return "Memory updated"  
  
@tool  
def clinical\_reasoner(patient\_id: str) -\> bool:  
    """Tool implementation for clinical\_reasoner."""  
    return True if patient\_id and len(memory\_store) \> 0 else False  
  
\# Fetch History  
  
@tool  
def fetch\_history(patient\_id: str) -\> dict:  
    """Tool implementation for fetch\_history."""  
    query\_embedding = np.random.rand(384).tolist()  
    results = collection.similarity\_search\_by\_vector(query\_embedding, k=3)  
    previous\_visits = \[r.page\_content for r in results if r.metadata.get("patient\_id") == patient\_id\]  
    if results:  
        return {  
            "memory\_embedding\_index": 0,  
            "matched\_patient": results\[0\].metadata.get("patient\_id"),  
            "previous\_notes": previous\_visits  
        }  
    return {}
